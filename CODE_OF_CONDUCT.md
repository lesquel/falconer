# Code of Conduct

All Falconer repositories (falconer, falconer-app, falconer-hook, falconer-relay and falconer-web) adopt the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which
applies in full.

## In short

- Be respectful and welcoming, whatever someone's background, identity or experience.
- Give and accept constructive feedback; focus on what is best for the project and its users.
- No harassment, insults, sexualized language or imagery, personal attacks, or publishing others' private
  information.

## Enforcement

The maintainers enforce this code in issues, pull requests, discussions and any other project space. Report
unacceptable behavior to the maintainers through GitHub:

- use **Report content** on the comment, issue or pull request, or
- open a private report from the affected repository's **Security → Report a vulnerability** form and say it is a
  conduct report.

Reports are handled privately. Maintainers may edit or remove contributions, and warn, temporarily ban or
permanently ban contributors, following the Contributor Covenant's enforcement guidelines.
